# 0003 — Agent single-sourcing: one canonical source per agent

- **Status:** Accepted
- **Origin:** user (all platform pairs, generated);
  default (source format, reconciliation of plan-review)

## Context

Every agent shipped twice — `.claude/agents/<name>.md` for Claude Code and
`.github/agents/<name>.agent.md` for GitHub Copilot — and `the agent scaffolder`
told authors to "keep the body in sync" with nothing enforcing it. Seven of the
eight pairs differed only in frontmatter and tool wording; `plan-review` had
genuinely diverged (141 vs 176 lines, with guidance present in only one copy).
A platform check found that only a few frontmatter fields are
portable and that the ask-the-user tools differ: `AskUserQuestion` in Claude Code,
`askQuestions` in VS Code Copilot.

## Decision

- Each agent has **one canonical source, `agents/<name>.md`**: Claude Code
  frontmatter (`name`, `description`, `tools`) and a platform-neutral body.
- `the agent-sync generator` (**`regenerating agent copies`**) generates both copies. Lines
  that must differ sit in `<!-- platform:claude -->` / `<!-- platform:copilot -->`
  blocks closed by `<!-- platform:end -->`; `{{ask_tool}}` renders the ask tool's
  name per platform. Any other `{{…}}` fails generation.
- **`check-agents`** (in `make check`) fails on a generated copy that differs
  from its source, a missing copy, an orphaned copy and a malformed source; a
  fixture selftest covers each case.
- `the agent scaffolder` scaffolds the canonical source.
- `plan-review`'s divergence was reconciled once, deliberately, onto the fuller
  body (recorded in the P3 pull request).

## Consequences

- An agent change is one edit plus `regenerating agent copies`; drift is a failing gate,
  not a review comment.
- Seven pairs regenerated byte-identical, so the change was behaviour-neutral for
  them; the Copilot copy of `plan-review` now names its real ask tool.
- Generated copies must never be hand-edited — contributors used to editing
  `.claude/agents/` directly will see `check-agents` fail until they move the edit
  to `agents/`.
- The generator knows two platforms; a third tool means extending the renderer.
