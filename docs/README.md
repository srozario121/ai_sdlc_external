# Documentation

Research and evaluation artifacts for AI-assisted SDLC live here, one directory
per topic.

## Convention

```
docs/<topic>/
├── <topic>.md    # full-form deep dive — the primary, exhaustively-cited document
└── summary.md    # a short, skimmable summary of the full-form doc
```

- **Full form** — the complete write-up: context, findings, evidence, citations.
- **Summary** — a one-to-two page distillation for readers who want the takeaways
  without the full argument. Always links back to the full-form document.

Every new topic directory must be linked from the **Research Index** and
**Evaluation** sections of the top-level [`README.md`](../README.md).

## Sub-areas

- [`research/`](research/) — deep research on AI SDLC approaches.
- [`evaluation/`](evaluation/) — how to measure the efficacy of AI SDLC flows.
